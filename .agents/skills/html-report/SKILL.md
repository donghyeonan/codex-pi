# HTML Report

이 주제를 처음 접하는 독자에게, 번호를 붙여 한 줄씩 이어 가는 블로그 글로 설명한다.

## 글

- 도입은 두세 줄로 무엇을 왜 쓰는지 말한다. 길면 어디부터 읽으면 되는지도 알려 준다("1~10번은 배경이니 알면 11번부터").
- 본문은 처음부터 끝까지 이어지는 번호로 쓴다. 번호 하나는 보통 한 문장, 음슴체(~임, ~함)다.
- 다음 번호는 앞 번호를 받아 이어 간다. 큰 이야기를 먼저 던지고 다음 번호들에서 푼다.
- 처음 나오는 용어는 바로 다음 번호에서 쉬운 말로 푼다. 숫자는 구체적으로 쓰고, 필요하면 직접 계산해 보여 준다.
- 흐름 한 덩어리가 끝나면 `한줄 코멘트.`로 해석을 몇 문장 붙인다. 번호에는 사실을, 코멘트에는 해석을 쓴다.

예:

> 1. 핵심은 복리가 시간이 길수록 훨씬 커진다는 것임.
> 2. 복리는 이자에도 다시 이자가 붙는 방식임.
> 3. 100만원을 연 10%로 두면 1년 뒤 110만원이 됨.
> 4. 2년째에는 110만원에 10%가 붙어서 121만원이 됨.
> 5. 30년이면 약 1,745만원으로, 원금에만 이자가 붙는 단리(400만원)의 4배가 넘음.
>
> 한줄 코멘트. 그래서 같은 수익률이라도 일찍 시작하는 쪽이 유리함.

## 보여 주기

- 원본은 해당 번호 바로 뒤에 넣는다. 원본 캡처(data URI 이미지), 기사·자료 링크, 원문 인용을 쓰고 여러 개를 넣어도 된다. 인용은 원문 그대로 두고, 외국어는 번호에서 우리말로 요약한 뒤 원문을 붙인다. 캡션에는 출처를 쓴다.
- 데이터는 실제 값으로 그린 inline SVG 그래프로 보여 준다. 비교는 막대, 추이는 선, 구성은 도넛이나 누적 막대, 분포는 히스토그램이나 상자그림, 관계는 산점도, 교차는 히트맵, 효과 크기는 포리스트 플롯을 쓴다.
- 새로 그린 도식은 캡션에 `AI 보충 도식`이라고 쓴다. 수치와 인용은 출처와 대조하고 지어내지 않는다.

## 파일

- 스타일은 [templates/anthropic.html](templates/anthropic.html)(기본) 또는 [templates/velog.html](templates/velog.html)(요청 시)를 쓴다.
- 독립 `.html` 하나로 만든다(외부 요청 없음). 위치는 요청을 따르고, 없으면 `.codex-pi/reports/<주제>.html`이다.
- 브라우저로 열어 확인하고 경로를 알려 준다.
