# HTML Report

독자는 이 주제를 처음 접한다고 보고 기초부터 설명한다. 블로그 글처럼 편하게 읽히게 쓴다.

## 글

- 번호를 붙여 이어 쓴다(1. 2. 3. …). 번호 하나에 이야기 하나를 몇 문장으로 담는다.
- 다음 번호는 앞 번호를 받아 이어 간다. 따로 노는 목록이 되지 않게 한다.
- 앞쪽 번호에서 무엇을 이야기할지와 결론을 먼저 말한다.
- 처음 나오는 용어와 약어는 그 자리에서 쉬운 말로 푼다.
- 긴 글은 소제목으로 나눠도 된다.

## 보여 주기

- 원본이 있으면 그대로 보여 준다. 원본 캡처(data URI 이미지), 원문 인용, 코드 발췌를 해당 번호 바로 뒤에 넣는다. 여러 개를 넣어도 된다. 캡션에는 무엇을 볼지와 출처를 쓴다.
- 데이터는 실제 값으로 그린 inline SVG 그래프로 보여 준다. 비교는 막대, 추이는 선, 구성은 도넛이나 누적 막대, 분포는 히스토그램이나 상자그림, 관계는 산점도, 교차는 히트맵, 효과 크기와 신뢰구간은 포리스트 플롯을 쓴다.
- 새로 그린 도식은 캡션에 `AI 보충 도식`이라고 쓴다. 수치와 인용은 출처와 대조하고 지어내지 않는다. 큰 원본 표는 검색·정렬되는 하위 페이지로 링크한다.

## 파일

- 스타일은 [templates/anthropic.html](templates/anthropic.html)(기본) 또는 [templates/velog.html](templates/velog.html)(요청 시)를 쓴다.
- 독립 `.html` 하나로 만든다(외부 요청 없음). 위치는 요청을 따르고, 없으면 `.codex-pi/reports/<주제>.html`이다.
- 브라우저로 열어 확인하고 경로를 알려 준다.
