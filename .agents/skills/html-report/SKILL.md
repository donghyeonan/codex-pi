# HTML Report

독자는 이 주제를 전혀 모른다고 가정한다. 무엇을 아는지 추측하지 않는다. 모든 개념을 1원칙부터 설명한다.

본문을 줄글로 먼저 쓰고, 아래 기준으로 고친 뒤 템플릿에 넣는다.

## 글

- 두괄식으로 쓴다. 글·절·문단 모두 결론이 먼저다.
- 문장은 짧게 쓴다. 한 문장에 한 내용만 담는다.
- 다음 문장은 직전 문장의 단어를 받아 이어 간다. 새 내용은 앞 내용과의 관계를 밝히고 들어온다. 맥락이 갑자기 바뀌지 않게 한다.
- 용어는 처음 나올 때 정의한다. 그 정의에 쓰인 개념도 모를 수 있으면 거기까지 내려간다. 약어는 풀어 쓴다.
- 추상적인 설명 앞에 구체적인 예를 하나 든다.

## 보여 주기

- 원본이 있으면 그대로 보여 준다. 원문 인용, 원본 캡처(data URI 이미지), 코드 발췌를 쓴다. 필요한 문장 바로 뒤에 두고, 여러 개를 넣어도 된다.
- 캡션에 무엇을 볼지와 출처를 쓴다. 인용은 원문 그대로, 생략은 `[중략]`. 외국어는 번역을 본문에, 원문을 `details`에 둔다.
- 데이터는 그래프로 보여 준다. 실제 값으로 inline SVG를 그리고 숫자도 적는다.
  - 비교: 막대 · 추이: 선 · 구성: 도넛, 누적 막대
  - 분포: 히스토그램, 상자그림 · 관계: 산점도 · 두 범주 교차: 히트맵
  - 효과 크기와 신뢰구간: 포리스트 플롯
- 새로 그린 도식은 캡션에 `AI 보충 도식`이라고 쓴다.
- 수치·인용은 출처와 대조한다. 지어내지 않는다. 큰 원본 표는 검색·정렬되는 하위 페이지로 링크한다.

## 파일

- 스타일은 [templates/anthropic.html](templates/anthropic.html)(기본) 또는 [templates/velog.html](templates/velog.html)(요청 시). 둘 다 한 칸이다.
- 독립 `.html` 하나(외부 요청 없음). 위치는 요청을 따르고, 없으면 `.codex-pi/reports/<주제>.html`.
- 브라우저로 열어 확인하고 경로를 알려 준다.
